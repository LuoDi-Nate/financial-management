## 0 · 这一版在解决什么

**背景与现状**:全站按钮(约 350 处 `btn-ink` / `btn-paper` / `btn-ghost` / `btn-brass`)都是同一种做法:12px 等宽字体、大写、0.12em 字距、上下 12px 内边距、直角。
- 一个按钮约 42px 高。
- 中文被字距拉成「添 加 持 仓 · 自 动 估 值」。
- 持仓页一排 5 个这样的按钮;每张持仓卡右侧再竖着叠 3 个整宽的大方框(改份额 / 改回手填 / 归档),一张卡里按钮比数据还抢眼。
- 标签(`pill`)同理:硬边框 + 等宽字体 + 字距。
- 填报页账户卡上,「本月已校准 · 07-16」这个带框小标签按基线对齐,比账户名低约 3px。

**服务谁**:三类都受益,主要是**非技术家人**。大方框按钮让页面像后台工具,而且一屏放不下几行数据。

**主推动力**:控件规格(尺寸、圆角、字体、层级)对齐主流组件库。配色和版式是否一起换,由方向 A / B 决定(§3.0)。

**本版新引入的名词**:无。

## 1 · 调研

见 [`docs/research/ui-frameworks-2026-10.md`](../docs/research/ui-frameworks-2026-10.md):shadcn/ui、HeroUI、Mantine、Nuxt UI、shadcn-vue、PrimeVue、daisyUI 七个组件库,加 Magic UI、Aceternity、React Bits 三个动效库。数值均取自官方源码。

一句话结论:
- **主流共识**:按钮 32–40px 高、圆角 4–8px、14px 无衬线、字重 500–600、**不大写不加字距**、一行最多 2–3 个,再多收进「⋯」。
- **我们全反着来**。
- **这些库都不能直接装**:我们没有 React / Vue,也没有构建管线。所以移植它们的数值,类名不变,全站一次换完。

## 3 · FR

### 3.0 · 要你先定的:方向 A 还是 B

两个方向都是把 CSS 叠到 **beta 真实页面**上拍的(隐私模式,金额已糊):

| | 方向 A · 精修账册(推荐) | 方向 B · shadcn 中性 |
|---|---|---|
| 换什么 | **只换控件**:按钮、标签、输入框、卡片圆角 | 控件 + **整站配色和字体**:白灰底、无衬线标题、白卡片 |
| 保留什么 | 米色纸底、衬线标题(Fraunces)、铜色强调、等宽数字 | 只保留铜色作点缀 |
| 按钮 | 32px(卡片内 28px)· 圆角 6px · 13px 中字重 | 36px(卡片内 32px)· 圆角 8px · 14px 中字重 |
| 标签 | 圆角 4px 软底 | 胶囊 |
| 风险 | 小:配色、版式、图表都不动 | 大:图表配色、印章、报表封板这些「账册」元素要逐个重新调,工作量大约是 A 的 3 倍(估) |

### 3.1 · 要求(按方向 A 写;选 B 时尺寸照 §3.0 表格换)

| # | 要求 |
|---|---|
| FR-1350 | 全站按钮默认 32px 高、卡片和行内 28px、登录这类大入口 40px;圆角 6px;无衬线 13px 中字重;**不大写、不加字距**;图标 14–16px。 |
| FR-1351 | 按钮分四层,看一眼就知道哪个是主操作:主操作实心深色(每个区块 1 个);次操作白底细边;行内轻操作无底无边、悬停才出浅底;删除 / 归档这类不可逆操作用单独的危险样式(红字、浅红底),不再和「编辑」同一个样子。 |
| FR-1352 | 所有按钮有统一的四种状态:悬停换底色、键盘 Tab 到时有清楚的光圈、按下时下沉 1px、请求中或不可点时变半透明(现在请求中的按钮外观不变,会被重复点)。 |
| FR-1353 | 一行最多 3 个按钮。持仓卡右侧三个竖排整宽按钮改成一排小按钮(「改份额」的表单改成浮层,不再挤开同排按钮);持仓页顶部 5 个按钮改成「主按钮 +『添加其他 ▾』菜单 + 手动刷价」三个,菜单点外面或按 Esc 收起。 |
| FR-1354 | 标签去掉硬边框和字距,改成圆角软底小标(11–12px);基金代码、股票代码这类仍用等宽字体。 |
| FR-1355 | 标签、按钮和旁边的文字放在一行时,按竖直中线对齐:填报页账户卡「账户名 · 本月已校准 · 类型」三者中线差 ≤1.5px(**已修,已在 beta**)。 |
| FR-1356 | 输入框、下拉框和按钮同高、同圆角,放在一行时上下对齐。 |
| FR-1357 | 「沉淀」:新规格写进 `docs/design-system.md` 的按钮 / 标签规范,替换掉「圆角 > 2px 破坏账册隐喻」那条旧规矩;再加机器护栏,按钮类里再出现大写或宽字距就红。 |
| FR-1358 | 「所有页面都要调整」(维护者 10-19):顶栏导航、手机菜单、字号钮、下拉菜单浮层、分段切换、筛选 chip 这些**按钮以外的可点控件**同样去掉等宽大写宽字距、补圆角;删除 / 归档 / 清除 / 断开等不可逆操作全站统一成危险样式;AI 入口统一成铜色软底按钮。 |
| FR-1359 | 验收中追加(维护者 10-19):顶栏品牌名旁的小图标从古钱(外圆内方)换成**存钱罐**,与「账房」字身中线对齐(原来低 2px);手机菜单字号回到和电脑顶栏一样的 13px(第一轮改成 15px 比原来大一圈);版本号前的小菱形保持菱形(第一轮被通用圆角规则磨成了圆)。 |

**关键文案**:「添加其他 ▾」菜单 —— 场外基金(按代码自动估值)/ 手填市值(未上市 / 拉不到价)/ 账户内现金。基金账户主按钮是「添加持仓 · 场外基金」,菜单里不再重复;贵金属账户只剩「账户内现金」一项,直接摆成按钮、不出菜单。「手动刷价」是动作不是「添加」,留在外面。

## 4 · 不做什么

- **不引入任何组件库**(React / Vue / daisyUI / HeroUI CSS):没有构建管线;两个能 CDN 引的都带 Tailwind v4 的样式重置,会和现有 Tailwind 3 冲突(见调研 §0.2)。
- **不加炫技动效**:光束、粒子、3D 卡片都不做。数字滚动(调研 §2 的 Number Ticker)单独评估,不在这一版。
- **不改信息结构**:页面上有哪些数据、按什么顺序,一律不动。只改控件长相,外加 FR-1353 的按钮收纳。
- **方向 A 下不动配色、标题字体、图表配色**。
- 不撞「刻意不做」清单。

## 9 · 失败模式(pre-mortem)

| 可能怎么失败 | 防法 |
|---|---|
| 某个页面靠按钮的旧尺寸撑版式(并排对齐、等高网格),换完错位 | 全站 e2e 跑一遍 + 双端截图逐页过(填报 / 仪表盘 / 报表 / 账户 / 持仓 / 管理 / 体检) |
| 有模板用 `text-transform:none` 之类的补丁抵消旧样式,新样式下变成多余或冲突 | grep 全部 `btn-*` 上的行内覆盖,逐个清理 |
| 新增页面又写回大写 + 宽字距 | qa-run 护栏扫 `style.css` 的按钮类 |
| 移动端点按区域变小 | 手机端按钮最小 36px 高(调研里 HeroUI 手机端也是比桌面大一档) |

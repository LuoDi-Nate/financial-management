## 0 · 这一版在解决什么

v1.39退休目标已经正确显示A/F,但达成日期仍藏在“按现在的结余,什么时候能达到”的可选投资预测里。列表的一条进度不能同时回答“已经有多少”与“按当前积累能力还需多久”。通用目标目前只有一个追踪指标,展示结构也将目标和单个指标绑定在一起。

服务维护者、非技术家人和自建用户。主推动力是**在目标的同一个入口同时读到现状与按当前结余的达成时间**,不增加月度填报。

目标继续有一条达成条件,在它下面展示多项观察指标。资金完成度、缺口、按结余预计达成、截止日对照是不同指标;不会把多个数平均成一个“综合完成度”。

本次“时间进度”明确指**预计达成月份 + 从今天起还需多久**,不是把日历已经过去的比例冒充新的完成度。可有多项指标,不等于每个目标都适用所有指标。

### 本期适用范围

| 目标/主指标 | 补充指标 | 结余预计日期 |
|---|---|---|
| v1.39新退休目标 | 资金完成度、缺口、预计达成、希望日期对照 | 支持,同一A/F的缺口 |
| 教育金、应急储备 | 资金完成度、缺口、预计达成、期限对照 | 支持,复用其当前资金与目标金额;应急仍保留原储备月数口径 |
| 自定义增长目标:金额合计、现金合计、累计净投入、总资产 | 主指标、缺口、预计达成、期限对照 | 支持,须为“达到”方向;总资产按其既有范围,不声称都能立即变现 |
| 收益率、储蓄率、占比、回撤、环比 | 当前值、目标值、差额、原有截止信息 | 不支持按月结余线性预测;缺口用百分点,不显示伪日期 |
| 累计/本期投资损益 | 当前损益、目标、差额 | 不支持:投入本金不等于投资收益 |
| 还债等“降到”方向 | 当前负债、目标、原有截止信息 | 本期不新增结余日期:真实还款要拆本金/利息及来源,不是收入减支出的简单外推 |
| 旧退休目标未采用新算法 | 原有指标和旧预测 | 保持兼容,不静默采用新退休算法 |

### 时间指标的计算合同

- 当前资金A、当前目标资金F与原有主进度使用**同一份**结果;不足额G=max(F−A,0)。不再扣一次准备金或负债,也不改小Lin分母。
- G=0时为“已达成”,剩余0个月。先判断此状态,即使结余来源暂缺也成立。
- G>0且本目标月可用结余C>0时,N=ceil(G/C),从当前基准月起往后N个月的**月末**为预计达成月。示例:2026-11、500万/1000万、每月4万,50%保持不变,还需125个月即10年5个月,预计2037-04。
- 这是仅按当前金额和结余不变的筹备估算。退休分母仍由小Lin算法得出;其中的长期实际回报假设不代表本时间指标又计算了一遍未来投资复利。
- 计入回报的原有未来积累仍走原有购买力模型、准备金/负债归属和已保存假设,不与本指标共用一个无名称的“预计日期”。不静默开启或改写原有 `simulateFuture`。
- C=0/负数时显示“按当前结余暂无法缩小缺口”,不显示无穷大、不猜涨薪。C缺失时显示“暂无完整月结余,可手填估算”;资金指标继续正常。
- 已知C且N>600时显示“按当前结余需超过50年”,不把“50年内未达到”说成永远达不到,不显示上一组残留日期。
- 周账期不将6周冒充6个月;本小迭代自动月度来源不足时可手填,不阻止目标配置。
- 视图币种切换时A/F/C同比缩放,完成度、N和预计月必须相同。

### 交互

1. **目标列表**:每个可预测目标一行主完成度+一行预计时间。主百分比仍只有一个,日期不用第二条伪百分比进度条。
2. **退休详情**:继续“退休生活账 / 调整计划 / 怎么算的”,共同外框不随tab切换。首屏新增时间指标,缺口与完成度保留。希望日期以一条起止时间轴作对照,不把时间轴着色比例称为完成度。
3. **调整时间估算**:从时间指标旁直达,或在调整计划内同一个位置。自研选项/单选按钮,不出现系统选择器;选择手填时即校验合法金额,首错在字段旁,不是点保存后才弹笼统报错。
4. **数据参考**:目标当前资金与目标金额、家庭结余逐月来源可展开,平时不铺满警告。未保存估算不覆盖列表和其它页面的已保存口径。
5. **非适用目标**:紧凑列表只展示已有指标和期限;详情的原理里解释为什么不能从月结余推投资收益率日期,不放一张空的预测卡。

预览包含目标列表、退休/教育/应急/自定义详情、三个固定宽度页签、结余设置、来源表及缺失/零/负/已达成/超50年等合成示例。

预览的“调整计划”只展开本期新增的时间估算区域;正式实现保留原有生活安排、资金范围、准备金与回报设置,不会用这一个结余表单替换整张退休配置页。

## 4 · 不做什么

- 不增加任意公式编辑器、指标市场、多条达标条件的AND/OR编辑器或可拖拽仪表盘;先让一个目标的多个可读指标成立。
- 不做家庭资金分配优化器,不自动替用户在目标之间转钱、分账或记流水。
- 不替换既有带投资回报的退休情景预测,不修改小Lin分母、A/F或历史投资回报资格。
- 不做逐笔手工记账、预算包络、券商下单;不引入外部模型或新数据源。
- 不在PRD阶段实现服务端多指标框架、写数据库迁移或部署beta。

## 7 · 开关与默认值

- 新指标在本PRD通过并后续实现后,对适用的目标直接展示只读结果;它不改变主指标或任何已保存的投资预测开关。这是本次明确要求的视图增量,无需让用户先保存/启用一次才能看到。
- 默认来源为已保存的有效结余偏好;从未配置则读家庭自动月结余。默认估算不包含未来收益、加薪或通胀变化。
- 手填优先值、希望日期和是否开启原有投资情景均保留。无希望日期不产生必填项。

## 8 · 隐私与数据红线

不新增LLM或对外调用。来源表只显示本家庭可见的月份与聚合收支,遵守家庭隔离和金额隐私开关;日期和百分比保持可见。原型全部为合成数据,不读取beta或prod业务数据。

## 9 · 失败模式

| 风险 | 发现方式 |
|---|---|
| 把月收入全额当月投入,或用消费预算代替全部支出 | 收入/支出差值及还款样本核对 |
| 为每个目标都套同一份家庭结余,误导为能同时达成 | 列表常驻独立估算说明;手填偏好按目标隔离 |
| 把本金投入预测用于收益率、投资损益或负债 | 明确适用表的正反样本,不按金额类型粗分 |
| 新指标缺来源再次使主进度消失或保存失败 | 同一目标缺/零/负结余对照,检查A/F及配置状态不变 |
| 与原有投资预测日期同名,或跨页算出不同结果 | 每个日期带口径,列表/详情/仪表盘同源;报告保留观察期 |

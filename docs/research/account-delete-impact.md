## 〇 · 先回答「我们是不是把归档当删除在用」

**是的,而且两者不是一回事。**

| | 归档(现在有) | 删除(要做的) |
|---|---|---|
| 历史月份 | **不动**:归档之前的月份照常算它(`FactMapper.xml` `archived_at > period_end`) | **全部改写**:它在每一个月的余额、流水都没了 |
| 本期起 | 不再计入;它的余额在本期「消失」→ 本期看起来像亏了这么多 | 从来不存在过,不会出现「本期亏了」 |
| 和别的账户的划转 | 保留 | 要决定怎么处理(D3) |
| 适合 | 账户真实存在过、现在不用了(卖光的券商账户、销户的卡) | **建错了 / 测试用的 / 从来不该存在的** |

所以删除不是归档的加强版,是另一个场景。确认弹窗里要说清这个区别,并给一个「其实你要的是归档」的出口。

## 一 · 关键事实(决定了影响范围)

1. **报表上的「封板」数字一个都没有存下来,每次打开都按当时的数据现算。** `SealedPeriodService` 自己写了「为什么不落库」(:39-45);「口径 v2」只是代码里的常量,没有表。存下来的只有「关账时冻结的账户属性」(类型、流动性、类目基准、分组 —— `period_account_attr` / `period_account_group`),那是**输入**不是结果。
   → **删一个账户 = 所有包含它的历史月份(含已关账的)报表数字都会变**,而页面上的「口径 v2」不会变。
2. 账户的数据散在**约 20 张表**里:余额 `period_snapshot`、待填 `snapshot_todo`、收支 `cash_flow`、划转 `transfer`(两头)、持仓 `stock_holding` + 估值事件 + 份额变动 + 截图导入、补录本金、冻结属性 / 分组、分组成员、保单、券商关联、目标绑定、再平衡计划条目、账单导入批次 / 规则、其它贷款的「默认还款来源」。其中 8 张有外键约束(只有「分组成员」会跟着级联删),其余要按顺序手动删;没有外键的(持仓、补录本金、冻结分组、计划条目、目标绑定……)删漏了也不报错 —— 最容易留下孤儿数据。另外「资产透视」里存的看板配置可能按账户名筛过。
3. 现在**没有任何删除账户的代码**;做的话是一条新的写路径。

## 二 · 需要你拍板的(D1 ~ D12)

**维护者 2026-10-12 裁定**:D1 **软删**(「任何情况我们还是要留一点点回转的余地」)· D2 A(「不然我们干嘛要那么沉重的要求用户知晓删除的危险」)· D3 **B**,且「要在给用户的提醒里面出现,告诉用户 xx 账户有多少钱的转入 / 转出由于这次改动要怎么样」· D4 ~ D12 全 A · D6 按建议。弹窗参考「看 AI 收到了什么」的命令行形态,确认文字要明细到每一期、每个账户、每一笔划转。

### D1 · 删到什么程度
- **A(建议)真删**:上面 20 张表里属于它的行全删,账户本身也删;只留审计日志里一条「谁、何时、删了哪个账户、删掉了什么(几期余额、几笔流水、几笔划转、几条持仓)」。
- B 软删:打标记、到处藏起来,数据还在(能恢复)。代价是每一条读数据的 SQL 都要加过滤,漏一处就是「删了还在算」—— 这个项目已经因为「两条路算同一件事只修了一条」吃过两次亏。

### D2 · 已关账的月份要不要跟着改
- **A(建议)跟着改**(你说的「该怎么变怎么变」):弹窗里列出会被改写的已关账月份。
- B 有已关账月份的账户不允许删,只能归档。

### D3 · 它和别的账户之间的划转怎么办(**影响最大的一条**)
例:被删的「测试账户」曾转 5 万给「工资卡」。
- A 划转一起删、工资卡余额不动 → 那 5 万在工资卡那一期变成「赚了 5 万」:工资卡的本期损益 / 累计损益 / 收益率 / 最大回撤、报表「本期归因」、家庭「钱赚」、XIRR、资产年化、财富水位全部跟着变。**会造出假的赚亏。**
- **B(建议)对方那一头改记成「本金进出」**:转进工资卡的 5 万改记成工资卡的「补录本金」(本金进来,不算赚);从工资卡转出去的改记成「本金移出」。工资卡的收益率、损益**一分不变**;家庭层面这 5 万变成「外部资本进出」(和开账基线同一类)。
  - 特例:对方账户在那一期是**第一次出现**(钱就是从被删账户转来开户的)→ 那笔钱自然并进它的开账基线,结果和 B 一致。
- C 只要它和别的账户有过划转就不让删(先去把划转一笔笔删掉)。

### D4 · 记在它身上的收入 / 支出流水
- **A(建议)一起删**。逐笔模式下,家庭的收入、支出、人赚、储蓄率、支出分析历史会变少;「每人填一个总数」模式的成员月度收支(`period_member_cashflow`)不挂账户,**不动**。
- (没有 B:流水必须挂在某个账户上。)
- ⚠ 一个连带后果:总数模式下,如果某个月的收入其实是进的这个账户,删掉后「人赚」不变、净资产变少 → 差额落进那个月的「钱赚」。弹窗里写一句。

### D5 · 删掉后本期「待填」变少
如果它是本期最后一个没填的账户,删掉后本期就算「全部填完」→ 可能**立刻满足自动关账条件**、报表默认看的那一期也可能跟着变。
- **A(建议)照常**,弹窗里写「删掉后本期就算全部填完了,到点会自动关账」。
- B 删除时如果会导致本期变成已填完,先不让删。

### D6 · 存下来的 AI 文本
- AI 月度复盘(`review_ai_cache`,只在已关账月份存):**建议清掉**涉及的月份,下次打开重新生成。
- AI 调仓建议(`rebalance_advice_cache`,30 天有效):**建议清掉**。
- 「看 AI 收到了什么」的历史记录(`llm_prompt_record`):**建议保留** —— 那是「当时发给 AI 的原文」,是历史事实。
- 资产透视的内存缓存:删完**立即刷新**(否则最多 12 小时还看得到它)。

### D7 · 再平衡计划里涉及它的条目
- **A(建议)删掉这些条目**,计划进度(x / y)会变;弹窗里列出来。

### D8 · 自定义目标绑了它
- **A(建议)解绑**,目标进度会变;如果目标只绑了它一个 → 目标卡上提示「绑定的账户都没了」。弹窗里列出来。

### D9 · 别的贷款把它设成了「默认还款来源」
- **A(建议)清空**那些贷款的默认还款来源,弹窗里列出来。

### D10 · 后悔药
- **A(建议)删除前自动做一次「立即备份」(v1.32 的能力),备份成功才删**;不做撤销按钮(真删之后撤销 = 从备份恢复)。
- B 不备份。

### D11 · 已关账月份被改写后,报表上怎么让人知道
- **A(建议)**报表上被改写过的已关账月份,在「关账于 …」旁边加一行「YYYY-MM-DD 删除账户『X』后重算」(从审计日志读,和「重新打开」留痕同一个思路)。
- B 不提示(只有弹窗那一次)。

### D12 · 谁能删
- **A(建议)和「归档」一样,家里任何成员都能删**,审计日志记名。
- B 只有账户的主理人能删。

## 三 · 确认弹窗(按你说的样子)

- 大弹窗、红色:**「删除账户『X』—— 不能撤销」**。
- 先写清和归档的区别,给一个「我其实是要归档」的按钮。
- **会被改写的月份**:「2025-05 至 2026-09 共 17 期(其中已关账 16 期)」,点开看每一期。月份很多时这样合并写,不逐个列。
- **会一起删掉的**:余额 N 期 · 收入 N 笔 ¥ · 支出 N 笔 ¥ · 持仓 N 条 · 补录本金 N 笔。
- **会被牵连的其它账户**(D3):「工资卡:3 笔划转改记成本金进出;余额宝:1 笔」。
- **会变的数**(预演,按 D 的选择现算):最近一个已关账月份的净资产、钱赚,删前 → 删后;本期净资产,删前 → 删后。
- D5 / D7 / D8 / D9 涉及的,有就列。
- 要求打字确认:框上方给出整句,例如
  `我知晓删除「测试账户」会改写 2025-05 至 2026-09 共 17 个账期`
  旁边一个「**复制这段话**」按钮;粘贴或打字,**一字不差**才点亮红色的「删除」按钮。
- 点了 → 先「立即备份」(D10)→ 备份成功 → 删除 → 回到账户簿,顶部提示「已删除,删除前的备份在 …」。

## 七 · 顺手查到的问题(和删除无关,先记下,要不要修你定)

排查时发现的几处现有口径 / 显示问题,都还没修、也还没在页面上复核:

1. 报表「汇率日期」显示的是账期最后一天,不是真实取汇率的日期(`SealedPeriodService` :169)。
2. 储蓄「月储蓄能力(中位)」标签写近 12 期,实际只取 6 期(`HouseholdCashflowService` :121)。
3. 报表「风险等级分布」不跟着选中的账期和币种,永远看当前进行中那一期(`FamilyDiagnoseService` 调用处)。
4. 报表「紧急储备」「即时可用可覆盖 N 月」的分母(月均支出)是按今天往前数 12 期,不是按选中的已关账月份 —— 已关账月份的这两个数会随时间变。
5. 支出分析「同比」一边是去年全家总支出、一边是今年只算日常开支,两边口径不一致(`ExpenseAttributionService.yoyText` :239)。
6. 「本金净流入 vs 投资损益」选 ALL 且超过 13 期时,横轴标签和柱子错位。
7. 一次性支出页的明细金额是原币种,没换算。

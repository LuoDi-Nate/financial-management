## 入口与验收重点

| 入口 | 核对行为 |
|---|---|
| 目标 → 新建 → 退休 | 四组设置沿用账户登记样式;默认全家可支用金融资产,账户选择折叠,全家净资产另列 |
| 每月生活费 | 手填与动态二选一;切换保留手填值;动态金额列实际月份、报表支出与剔除额,不足3个月不造数 |
| 大额支出准备金 | 养老日常开销已在生活费X中。选城市即显示已知推荐分项;子女或住房未填不清空独立医疗/应急值,未知不当0;已在生活费里的费用不重复预留 |
| 表单与保存 | 下拉含动态年数统一自研;配置缺必填在字段旁提示且不发保存请求。AUTO数据不足仍可保存并明确“配置已完成 · 已保存”,各运行指标按依赖保留,来源提醒默认折叠;自定义只存账户选择 |
| 正常未关账 | 进行期余额缺本月填写但有历史时沿用最近已知值;只有真正无历史来源的账户暂缺,已知小计不冒充完整覆盖率,无需为创建目标提前关账 |
| 回报与通胀 | 动态回报至少12个连续完整月度收益间隔;CPI采用10个完整核验年度。来源不足明确说明,节目示例必须主动采用 |
| 退休生活账 → 可选未来积累 | 默认折叠,启用后沿当前假设算一条路径;结余只改达到时间,不改本金门槛;高级项才比较三情景 |
| 已有退休方案 → 调整计划 | 保留原非零持续收入及结果,旧新门槛对照后明确升级;升级前完整JSON留存,可导出、可恢复;旧目标参数不覆盖 |
| 填报 → 固定收支 / 管理 → 固定收支 | 没设的贷款持续提醒;选每月自己填可停止提醒并可恢复;人工已提交本期余额的新还款从下期开始,系统延续余额可从本期开始 |
| 管理 → AI 接入 | 测试保护保持开启,拦截与发送分列;本家庭准备内容可查看,明确没有发送;历史结果仍能阅读 |

城市金额是产品规划起点,不代表官方城市统计或医疗报价。CPI逐年核验信息见管理页与退休来源表。原节目链接保留在“怎么算的”,不附带家庭数据。

CPI当前读取2016—2025已核验年度快照,后续年度发布后在“数据源接入”校正,页面展示核验年份与日期。账户余额、定稿支出与合格历史收益在每次演算时重新读取;缺少合格来源会直接指出,不当作零或套用示例。

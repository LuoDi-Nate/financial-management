# v1.37.1 封板报告指标核算

核算对象为维护者指定的已封板观察账期。本文只记录口径、结论及验收方法，不包含家庭真实金额、账户名、凭据或运维地址。

## 方法与边界

- 通过只读一致性事务取数，原始数据只在进程内存及管道中传递。没有生产 dump、JSON、HTML 或截图文件，也不复制到 beta。
- 已核对线上版本与本地原版业务源码一致。未直接登录生产页面；将同一份只读样本装入纯内存数据库，由原版及修复版实际控制器、mapper 和模板渲染，对照独立十进制运算。
- 内存数据库保留原列序、默认值及唯一键，禁用定时任务和真实 AI；发现仿真或检查器差异时先查清原因，不据此改业务代码。
- 覆盖 1M、3M、6M、1Y、YTD、ALL 与 CNY、USD、HKD 的 18 种组合，以及账期明细、支出逐笔、一次性明细和还贷工具入口。
- 金额按显示精度允许舍入噪声；百分比与百分点分别比较。单个期末快照没有收益区间，应显示不可计算；缺去年同期时留空，不编造同比。

## 覆盖与结论

| 区域 | 独立核算内容 | 结论 |
|---|---|---|
| 封板抬头 | 应填、已填、缺失与各余额来源计数 | 原来按账户类型猜自动/手填，且把未填算手填；改按当期快照来源，其他及未记录单列 |
| 资产负债表 | 净资产、总资产、负债率、流动资产、月均支出、样本数、应急月数 | 金额与比率核算一致 |
| 资金流与对照 | 期初、收入、支出、开账基线、投资损益、期末；上期及环比、同比缺失态 | 三项恒等式成立；汇率抬头改为账期，避免把月末当成报价日 |
| 归因与结构 | 逐账户扣净划转及本金后的贡献、占比；集中度、流动性分层、成员及资产类型分布 | 核算一致 |
| 收益趋势 | 家庭及账户收益、损益、净投入、回撤、基准、负债曲线 | 短期基准多计一个间隔已修；人赚卡片排除中途纳入本金，本金曲线保留本金语义 |
| 风险及配置 | 观察期各风险档金额与比例、配置占比、有效目标及差值 | 风险原来读当前体检和本位币，改用报表切片；配置核算一致 |
| 财富水位 | 剔开账基线的净资产、CPI/M2 逐段复利、三法均值、名义增长及百分点差 | 计算一致；修复币种符号、小金额被显示成零及币种切换后的局部刷新 |
| 储蓄 | 旧总额与逐笔择一、样本、均值、中位数、当期比率和曲线 | 旧取数漏掉后续逐笔月份且错期；卡片、图、说明面板统一同源，零收入不回退旧比率 |
| 支出 | 构成、当期及年度分类总额、常态月均、一次性、性质三分、归因和逐笔明细 | 构成与明细原来可能读后月或丢观察上下文，现沿用同一观察期/range；本位币金额不冒用显示币种符号 |

## 验收记录

- 全量 `mvn -o -q package`：1,287 单元测试通过。
- 18 组范围/币种组合共 8,856 次逐项比对全部通过；账期及支出等子页面另有 141 项通过。
- v1.37.1 六项静态守护通过；包含真实 mapper 的内存核对覆盖快照来源 SELECT，避免 mock 掩盖漏列。
- 浏览器主线 57 的 29 项断言通过：使用合成历史月份，从电脑顶栏及手机菜单进入，覆盖旧总额、新逐笔、后月排除、存量本金、维度和明细、切币种、零收入及退款；双端截图检查图表、金额和布局。
- 既有风险主线 25、补录本金与成本价主线 45、归因划转主线 46 通过。45 所需可写账期及与持仓一致的余额在隔离前置中补齐，结束恢复原状态；没有调用关账接口。
- 不执行会触发服务端关账异步模型调用的全量脚本；v1.38 服务端开关尚未实现。真实 AI 路径没有作为本补丁的回归手段。

# LLM API Key 申请与配置指南

入口:**管理 → AI 接入 → 大模型**,路径`/admin/ai-access#llm`。不用改代码或服务器文件。AI是可选能力,不配置时记账、净资产、收益和图表仍正常。

## 1. 平台、系列和型号

平台决定服务地址、密钥及账单;系列给参考型号;型号是实际发送的Model ID。硅基流动或方舟托管的DeepSeek与DeepSeek官方是不同平台,不能共用后者的密钥。

| 平台 | 密钥入口 | 文字 | 图片输入 | 自动策略 |
|---|---|---|---|---|
| 阿里云百炼 | [百炼控制台](https://bailian.console.aliyun.com) | 通义千问 | 通义千问VL | 文字留空沿用原型号池轮询,视觉用系列默认 |
| DeepSeek官方 | [官方平台](https://platform.deepseek.com) | DeepSeek | 本项目未提供 | 用系列默认 |
| 火山方舟 | [方舟控制台](https://console.volcengine.com/ark) | 豆包及方舟托管DeepSeek | 豆包视觉 | 有默认的系列用默认;无默认的托管系列需手填 |
| 硅基流动 | [中国站API密钥](https://cloud.siliconflow.cn/account/ak) | 参考系列或手填 | 参考图片系列或手填 | 有默认的系列用默认;“其他”系列需手填 |

参考项只是便于填写,不是对账户权限、余额、图片或工具能力的保证。平台可能调整型号,以对应控制台当前目录为准。

## 2. 获取密钥

四个平台都只需对应平台的一把API Key,不需要云AccessKey/Secret配对。申请步骤和账户要求以平台控制台为准。

### 阿里云百炼

1. 登录百炼控制台,按提示完成账号认证、开通服务。
2. 在API-KEY入口创建密钥,复制后粘贴到百炼凭据卡,点“保存密钥”。
3. 如希望限制在免费额度内使用,到平台开启“免费额度用完即停”。本项目保留百炼原有的自动型号池轮询,手填具体型号时只使用该型号。

### DeepSeek官方

1. 登录官方平台,到API keys创建密钥。
2. 核对账户余额及权限,保存到“DeepSeek官方”凭据卡。
3. 该平台在本项目只提供文字选择;需要截图识别时另配支持图片的平台。

### 火山方舟

1. 登录方舟控制台,完成账号实名认证。
2. 在“开通管理”开通所需型号,在“API Key管理”创建密钥。
3. 保存密钥后可选豆包参考型号,也可从模型广场复制完整Model ID;已有`ep-`接入点ID仍可手填。
4. 图片识别选择支持图片的型号或接入点。带日期型号失效时,到本平台复制当前型号;不要把方舟ID填到别的平台。

### 硅基流动

1. 登录硅基流动中国站,进入[API密钥](https://cloud.siliconflow.cn/account/ak),按控制台要求创建密钥。
2. 在“硅基流动”卡片保存,不要求先选主备或视觉型号。
3. 在下方文字主选或备选中选硅基流动。可用参考项,也可复制完整Model ID,例如带组织前缀或`Pro/`的型号;保留大小写,不填网址。
4. 截图识别单独选择有图片输入能力的型号。本地Agent所选文字型号还需支持工具调用;不是平台所有型号都支持这些能力。

本项目固定使用中国站,不提供任意代理地址或国际站切换。参考资料:[对话/图片接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[工具调用](https://docs.siliconflow.cn/docs/userguide/guides/function-calling)、[模型目录](https://docs.siliconflow.cn/docs/api/models-get)。

## 3. 保存与测试

四张凭据卡和下方三级选择采用相同规则:

1. **先存密钥**:每家独立保存。留空不修改原值,空提交也不会假报成功;已配置只显示脱敏值。保存Key不更换模型或Agent运行方式。
2. **再选模型**:主选/备选各是一组“平台 → 系列 → 型号”。未配Key的平台保留禁用提示。切平台或系列会清掉之前的型号,避免串用。
3. **留空或auto**:表示使用既有默认策略。百炼文字保留自动轮询,其它有默认的系列使用默认。没有默认的系列才要求手填;手填不受参考清单限制,但须满足安全格式,最长256字符。
4. **备选可不设**:选择“不设备选”。与主选完全相同的策略会提示修改。主选失败时按原策略切备选,已有用户可见的Agent产出后不会重播。
5. **截图独立**:关闭截图时,视觉字段不阻塞文字保存。没有已配密钥的图片平台时开关禁用并指路。截图失败不切文字备选,识别结果仍需人工确认。
6. **保存模型配置**:主备、视觉、温度、输出上限与超时沿用同一保存边界。无效输入定位首错,有效配置不被部分改写。设置下次请求生效,不用重启。
7. **测试连接**:只测已保存密钥及卡片上显示的型号,不使用未保存草稿。优先主选→备选→启用的视觉,都没选此平台才用参考文字型号。自动策略探测时固定一个型号,不整池检查。

测试连接会产生少量平台用量。一次通过只证明这次连接,不保证全部图片/工具能力。开启服务端模型测试保护时,明确显示“测试环境 · 未调用”,不能把它当成连接成功。

| 反馈 | 下一步 |
|---|---|
| Key无效 | 核对对应平台密钥,重新保存后再测 |
| 余额/权限不足 | 到这家平台核对账户权益、余额及所选型号权限 |
| 型号不存在/未开通 | 从这家平台复制当前完整ID,核对是否已开通 |
| 限流/繁忙 | 稍后重试或选择可用备选 |
| 网络/超时 | 核对服务端网络,稍后再试 |
| 测试环境未调用 | 是实例模型保护生效,没有发送真实模型请求 |

百炼托管Agent仍使用百炼账户与原独立运行设置;硅基流动不会替换它。本地Agent沿用文字主备。

## 4. 可选环境初始化

管理页是默认入口,DB中已保存的非空密钥优先。既有systemd部署的首次初始化样例新增空占位:

```dotenv
FINANCE_LLM_QWEN_API_KEY=
FINANCE_LLM_DEEPSEEK_API_KEY=
FINANCE_LLM_ARK_API_KEY=
FINANCE_LLM_SILICONFLOW_API_KEY=
```

首次初始化仍遵守原幂等标记,后续部署不覆盖管理页修改。硅基流动同时支持应用属性`finance.llm.siliconflow.api-key`及显式环境fallback`FINANCE_LLM_SILICONFLOW_API_KEY`,但不要求用户使用它们。Docker用户直接在管理页保存即可,不要把Key提交到公开compose或代码里。

## 5. 隐私

Key只用于对应平台认证,不进入prompt、日志明文、审计正文或页面明文回显。不要把它粘到型号字段,也不要提交到git。

启用某个平台后,你主动使用的AI能力会向它发送该入口准备的材料。分析类文字沿用成员/账户代号映射;超级Agent工具返回范围沿用原合同;截图可能自带个人信息,不承诺自动遮盖原图。可从AI结果旁的`>_`查看那次实际记录的提示词,不能据本文推断“任何AI入口都不含账户名或备注”。

测试与截图只使用桩、合成材料和服务端保护,不为验收自动发送真实家庭数据。

## 6. 用量

不承诺免费额度、充值最低金额或固定月成本。以所选完整型号在对应平台当期的价格、账户权益及实际用量为准。长上下文、图片、工具多回合及故障切备选都可能增加用量;保存设置本身不会发起模型调用。

## 7. 回退

需要停用硅基流动时,把主选、备选及启用的视觉切回已配密钥的原平台并保存。回滚到不认识新平台的旧程序前先完成这一步,不要依赖旧程序猜测新设置。保留历史报告和财务数据,无需回滚schema。

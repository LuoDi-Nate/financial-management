## 验收路径

1. 从顶栏“目标”进入目标列表,同一条目标同时查看资金完成度与按结余预计时间。主进度仍按原来的资金口径计算。
2. 打开一个已采用新算法的退休目标,首屏查看“按当前结余预计达成”“从现在起还需”和本目标月可用结余,展开来源查看采用的月份。
3. 点“调整时间估算”,在自动家庭结余与本目标手填之间切换。非法金额在字段旁提示;0和负数是合法配置,日期会说明缺口暂不缩小。
4. 修改主计划但不保存,再保存时间估算,主计划草稿应保留。只保存结余不会把希望月份固定成旧值;单独修改或清空估算希望月份才明确覆盖。
5. 在电脑与手机三个页签间切换,检查输入、来源展开状态、页面外框和可点击区域。
6. 在教育/应急/自定义资金积累目标查看同类指标;收益率、投资损益或负债收敛目标不套用本金积累日期。

多个目标引用同一份家庭结余时均为独立估算,列表会提示尚未分配这笔结余。原有投资回报情景单独保留;新日期只按当前目标金额和结余不变估算。

## 状态与口径

| 情形 | 应有行为 |
|---|---|
| 已有500万、所需1000万、月结余4万(合成例) | 资金进度50%;以2026-11为基准还需125个月/10年5个月,预计2037-04 |
| 缺结余来源 | 仅时间指标暂不估算,资金进度及目标保存继续有效 |
| 月结余为0或负数 | 不显示无穷大或猜测日期,明确缺口暂不缩小 |
| 资金已达成且结余缺失 | 已达成、0个月,不要求补收入才能判断 |
| 超过600个月 | 显示超过50年,不说永远达不到 |
| 手填金额的本位币已改变 | 提醒按当前本位币重新填写,不重新解释旧币种金额 |
| 未独立覆盖希望月份 | 继承主目标/退休计划;只保存结余不冻结旧月份 |
| 切换视图币种 | 日期、整数月数及比例不变,只转换金额显示 |
| 历史报表与旧AI月报 | 不混入新今日ETA,不自动重算或产生模型调用 |

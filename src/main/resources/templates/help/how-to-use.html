01
01必修

建账户

先把家里的钱分门别类装进账户。账户是这个软件的基本单位 —— 之后所有余额、收益、分析都挂在账户上。

去账户页建账户

10 类账户,16 个模板可套 账户 → 新建

现金 / 股票 / 理财 / 基金 / 加密 / 贵金属 / 房产 / 贷款 / 保险 / 其他。套模板(招行储蓄卡、余额宝、富途证券、蚂蚁财富…)会帮你把平台、币种、产品类目一并填好。

每个账户填三件事 主理人 · 平台 · 币种

主理人决定「按成员看」算谁的;平台决定「平台安全」视角;币种支持 CNY / USD / HKD 自动换算。现在随手填,后面分析时才有得切。

贷款账户 正负号系统自动处理

房贷、消费贷、信用卡都建成「贷款」类型,余额填还欠多少。填正数或负数都行,系统统一存成负债,不会算错。

02必修

每月填报

这个软件不用记流水。每月进填报页做三件事,顺序照下面来能少返工。

去填报页

① 先录收入(逐笔) 现金收入 / 股票收入

填金额 + 类目 + 这笔钱进了哪个账户。工资、奖金、股息、利息都这么记。录一笔,系统立即把钱加进那个账户的余额,还留一条流水。

② 再填支出 本月总支出 / 逐笔支出

支出有两种填法,自己选(默认「总额」,老用户升级后一切不变):

  • 总额 —— 每位成员各填一个数,从微信 / 支付宝 / 信用卡账单抄总数过来。不用拆分类、不用逐笔。
  • 逐笔 —— 每笔选账户 + 类目,自动从该账户余额扣除。多花点时间,换来整章支出分析(见选修 B8)与更准的账户级收益率。嫌敲得慢就用账单批量导入(选修 A6)。

在管理 → 提醒与模板 → 支出录入方式里切。切换不动任何已录数据: 切到逐笔后原来填的总额还在,切回总额后已录的逐笔也不删。

去切换支出录入方式

逐笔支出有两个各自独立的分类,别把它们混成一个:

  • 资金性质(必选)—— 日常开支 / 还贷 / 利息支出 / 转账给亲属。 它决定这笔钱算不算「可调的那部分」:还贷和利息压不下去,日常开支才是。这四个是内置的。
  • 消费分类(可选)—— 餐饮美食 / 交通出行 / 住房物业……一棵你自己维护的树, 大类下可以再分细类。点大类就能提交,想细分再多点一下细类,不强制也不用预先决定。

还有一个勾:「这笔是一次性的」。 买冰箱、换手机、一次旅行 —— 勾上它,这笔就不会污染「常态月均」那个数(见选修 B8)。 默认不勾,因为绝大多数笔不是一次性的。

去维护消费分类

逐笔录入会扣余额,所以第 ③ 步的顺序更要紧: 如果你已经照银行 App 填了月末余额(那个数本就含这笔消费),再录这笔就会扣第二次。 记住「先录收支,最后核对余额」就不会踩。

③ 最后核对余额 各账户行

收入已在第 ① 步自动进去了,这里通常只需确认。某账户忘填不会缺口(沿用上一期),但数就不准了。

跨账户搬钱要记一笔 账户间划转

从工资卡转 5 万去证券账户,用「划转」记 —— 系统知道那是搬家,不算收入也不算支出。不记的话总净资产还对,但账户级收益率会失真。

下面两台是仿真的填报页(控件与真实页面一致)。同一个月、同一笔工资, 只是操作顺序不同 —— 左边对,右边把工资算了两次。

收入 先选类型 · 现金填金额
+ 加一笔

余额 ¥26,519 正确。这笔钱既进了余额、也留下一条流水 —— 之后「人赚 / 储蓄率 / XIRR」都算得对。
① 先填余额 → ② 再录收入　（会重复计）
现金 招行储蓄卡-工资
照银行 App 填的,已含这月工资
收入 又去补录那笔工资
+ 加一笔
系统再次自动入账 26,519 + 10,000
现金 招行储蓄卡-工资
比银行 App 多了 10,000
凭空多了 ¥10,000。净资产虚高,而且这笔钱被当成「人赚的」算了两次 —— 储蓄率、收益率跟着一起错。

记住这条机制就够了:录一笔收入 = 往那个账户的余额上加一笔。 所以先录收入,余额会自己变对;反过来则会加两次。

03必修

关账

填报页会显示「家庭本月已填收支:N / M 人」和哪些账户还没填。都齐了就关账。

去周期管理关账

关账不是走形式 管理 → 周期管理

收益类指标(本月资产收益 / 家庭 XIRR / 资产年化 / 人赚钱赚)只统计已关账的账期。填报中的月份通常「余额填了、收支没录齐」,拿它算收益会把没录的收支当成投资收益。所以没关账 = 这个月不进收益统计,页面会标明当前算的是哪一期。

什么时候关,你自己定 管理 → 周期管理 → 关账节奏

系统原来在次月一开始就把上月锁上了,而微信 / 支付宝 / 信用卡最方便拿到的整月账单,要等月底过完才出 —— 于是「月初拿完整账单再填」这条最自然的路径反而得先去重开账期。现在四档任选:

  • 立即关账(默认,与老版本逐分一致)—— 新月份一开始,上月立刻锁上。月底最后几天的消费要自己补算进去。
  • 月底过完再给 2 天(推荐)—— 这 2 天就是拿来填完整账单的。
  • 月底过完再给 5 天 —— 信用卡账单日晚于月末的家庭适用。
  • 我自己关 —— 你决定什么时候。兜底:到下下个月开始时系统还是会关掉它,不会让一个月一直悬着。

每一档旁边都写着它的代价 —— 宽限期里上月还没关, 那段时间的收益类指标就仍然锚在更早的一期。这是选择,不是 bug。

宽限期里,两个月同时可填 填报页

选了 T+2 / T+5 / 我自己关之后,宽限期内上月与本月同时是「可填」状态,填报页把两期并排摆出来, 默认落在要补录的上月那一侧 —— 因为你这几天来,十有八九是来补上月的。

与之配套的两件事:批量导入默认记到上月; 报表锚住上月而不会倒退到上上月,并如实标注它「仍在填报中」。

看这个月发生了什么

仪表盘上由粗到细看四步,五分钟。

去仪表盘

① 概览 仪表盘顶部

净资产多少、比上月涨跌多少、紧急储备够几个月、总资产总负债各多少。

② 人赚 vs 钱赚 本期怎么变

资产变化里多少是工资攒的(人赚)、多少是投资赚的(钱赚)。等式:ΔNW = 人赚 + 钱赚 + 开账基线。

③ 归因复盘 归因复盘

变化具体由谁贡献,五个视角可切,带 12 期趋势。

④ 资产洞察 洞察条

系统按规则给的提示:负债率偏高、应急金不足、过度集中、可考虑提前还贷等。

一条总原则

记住这句,九成「这笔钱要不要记」的问题自己就有答案。

回填报页练一遍
不算收支

钱在你自己账户之间移动

转账、买基金、卖股票、还房贷本金 —— 你没变穷也没变富,只是钱换了个地方待着。只影响各账户余额。

算收支

钱真正进出你家

工资、奖金、吃饭、房租、利息 —— 收入逐笔录(选进账账户),支出填一个总数。

几个容易犹豫的场景
同一账户里买卖基金什么都不用做,月末余额自然反映
还房贷贷款余额减 + 现金减 · 利息自动体现
借钱给别人建「其他」账户记应收
股息 / 利息到账留在账户不用记 · 打进现金则录收入
补录一个已有钱的老账户直接建 · 自动识别为「开账基线」,不虚高收益
新开一个空账户,从别的账户转钱进去建好后在老账户那一行「↔ 划转」· 转进来的钱不算开账基线(左手倒右手,不影响收益)

支出账单批量导入

想要逐笔支出、又不想一笔笔敲:把支付宝 / 微信导出的账单传上来,一次几百笔。

去批量导入

渠道要你自己选 上传区

支付宝和微信二选一,我们不猜。两家的导出格式长得很像,猜错会把 微信的「交易类型」当成消费分类填进去 —— 那个错混在几百笔里,事后极难发现。 文件收 csv,或渠道发来的加密 zip(带上解压密码就行)。

银行 App 大多没有 csv 导出,这条路还没接上。 眼下的办法:银行卡里走支付宝 / 微信的那部分,导这两家就够了。

归类分三层,AI 只是最后一层 确认页

前两层是纯本地的(你之前定过的规则 + 内置词表),不联网、不花钱、立刻出结果。 剩下还没归上的,才有一个「让 AI 猜这 N 笔」的按钮,点不点随你。 点了也只转圈那一个按钮,整页照常能用,而且你手动改过的行永远不会被覆盖。

改过一次,下次自动命中 本页最下方「规则」

你在确认页手动改过的行会被记成规则,下次导入同类交易自动归好。 规则在这一页最下面看得到,也删得掉 —— 它不是黑盒。

导错了可以整批撤销 本期已导入

每一批导入都是一个整体,可以整批撤回;当初扣过余额的,撤销时会把钱加回去。 所以不用怕导错 —— 真要重导,先把那一批撤掉,别叠着导第二遍。

支出分析

报表里的「钱花在哪了」回答三个问题:钱花在哪、这个月为什么变了、这些钱砍不砍得掉。 这一章不给好坏评价 —— 花钱没有对错,只有可压缩空间大小。

去报表 → 钱花在哪了

先切到逐笔录入 管理 → 提醒与模板

这一整章只在逐笔模式下出现 —— 总额模式只有一个总数,没有构成可言, 硬塞一个空图比不显示更糟。切换不动任何已录数据,想回去随时回去。 嫌一笔笔敲太慢,看选修 A6 的账单批量导入。

去切换支出录入方式

两层,不是两块 报表 → 钱花在哪了

第一层按资金性质 —— 日常开支 / 还贷 / 利息 / 给亲属。这一层的合计就是家庭支出总额。
第二层展开其中的「日常开支」,按你自己维护的消费分类看:餐饮多少、交通多少。

两层各自都能切按类目 / 按账户 / 按成员三个维度, 窗口跟随上方趋势区(本期 / 近 6 期 / 近 12 期),点任意一格能展开那一格的逐笔明细。

这些钱砍得掉吗 三分条

日常开支再按「少了它日子过不过得下去」拆成三段:

  • 刚性 —— 过不下去的:房贷物业、水电、学费、看病。
  • 弹性 —— 难受但能过的。
  • 一次性 —— 这个月有、下个月没有的。

性质是消费分类的属性,在类目页一屏改完, 改完立即对全部历史生效,不回写任何一行流水。 单独某一笔要破例(刚性类目里买了台一次性的东西),在录入时勾「这笔是一次性的」,逐笔的勾优先。

去设置类目性质

常态月均:剔掉一次性之后的那个数 三分块下方

月均支出把买冰箱那个月也算了进去,所以它总是偏高。 常态月均剔掉一次性的部分,更接近「日子的基本开销」—— 算应急储备够撑几个月时,后面这个数才是你想要的。旁边写着这次剔除了几笔,点得开看是哪几笔。

这个月为什么变了 归因瀑布

把两期支出的差额摊到类目上,一眼看出是谁在推动。 读它的时候记住:金额差是主信息,变化率是次信息 —— 「旅游多了一笔」比「餐饮涨了 100%」更值得看。

不想等关账,仪表盘上有一份即时的 仪表盘

报表这一章锚的是最近已关账的那一期;仪表盘上那块「本月支出 · 砍得掉吗」是 本月至今,不用等关账。两处的窗口和基数都写在标题旁边 —— 它们差着一个数量级,别拿这边的百分比去乘那边的金额。

看不懂的数字,点它旁边的 ⓘ 每个算出来的指标

刚性占比、常态月均、本期支出、比上期……每一个都带 ⓘ,写清它是怎么算的、基数是什么、窗口是哪一段。 百分比一律把基数写在脸上,不用点开也能看见。

只填了总数的月份会如实标出来 段首提示

那些月份不在构成里(没有逐笔就拆不出构成),但它们的支出仍然照总额参与 储蓄率与人赚的计算 —— 不隐藏、不假装没有。落在已归档账户上的历史支出同理: 不计入构成,但会明确告诉你有多少笔。

整章可以关掉 管理 → 计算口径

不想要这套分析,一个开关关掉整章。关掉之后别处引用「常态月均」的地方也一起消失, 不会留下半开状态。

一步步拿到富途 / 老虎 / 盈透的配置

配好之后,系统每天(或你手动点一下)只读把券商里的持仓 + 各币种现金拉进账房,不用再手抄。下面按券商分三份,照着做即可。

先 · 说 · 安 · 全
  • · 本系统只查询、永不下单 / 划转:富途只连本地网关查数据、从不解锁交易;老虎只调查询接口;盈透 IBKR 用的「报表口令」本身就只能取报表,做不了交易。
  • · 但你即将拿到的这把私钥 / 网关本身权限较大,请当成密码一样保管;担心时随时能在券商后台吊销 / 重置。
  • · 凭据在本机加密保存,页面上私钥永不回显。
期 · 权 · 期 · 货 · 债 · 券 · 怎 · 么 · 记
  • · 期权 / 权证 / 债券:一张合约一行,市值用券商给的持仓市值(已含合约乘数,美股期权通常是 100)。卖出的是负数,从账户余额里减去 —— 这样账户余额和券商那边的净值对得上。
  • · 期货:只展示名义价值,不计入余额。期货盈亏每天结算进现金,现金里已经有了;按名义价值记会把几千块保证金的合约算成几十万。
  • · 到期或平仓之后,下次同步自动从持仓里拿掉;行权、被指派变成的股票,下次同步自然出现在股票那一行。
  • · 某一行数据不全或自相矛盾(张数 × 标记价 × 乘数 和市值对不上),这一行不同步,同步结果里会点名 —— 不拿猜的数顶上。
  • · 升级后第一次同步:新关联的账户,这些都算开账时就有的;已经在记的账户,余额会因为期权等「第一次被算进来」跳一下,这一跳计入当月收益,当月收益率会因此偏高一次。以前为了凑数手填过一条期权市值的,记得把那条归档,免得算两遍。

富途 Futu 主推 · 一键安装向导全自动托管 OpenD(手动部署为进阶)
主 · 推 · 一 · 键 · 安 · 装

富途要经 OpenD 网关,但不用你手动装 —— 用应用内向导,系统帮你下载、启动、守护 OpenD,短信验证码也在页面里填,全程点鼠标;完成后连接参数自动回填,直接去账户页点「关联」即可。

打开一键安装 / 托管 OpenD 向导

前置只有一件:先在富途牛牛 App / 网页完成一次「问卷 + 协议确认」(账号级,任何程序替不了)。

开始前

你得有富途牛牛账户并开通了对应市场权限。富途的机制是:官方给一个叫 FutuOpenD 的小网关程序,你在自己电脑上运行它、用富途账号登录;我们的系统连这个本地网关来只读取数据。网关关掉就同步不了,所以最好放在一台常开的电脑 / 服务器上。

手动方案(进阶 · 不用向导时才需要)
  1. 1
    下载 FutuOpenD 网关

    到富途 OpenAPI 下载页,下载 FutuOpenD。有「可视化(带界面)」和「命令行」两种 —— 入门选可视化版更省事。支持 Windows / Mac / Linux。

    futunn.com/download/openAPI
  2. 2
    运行 OpenD,用富途账号登录

    打开 FutuOpenD,输入富途账号 + 登录密码登录。首次登录可能要完成一次问卷 + 协议确认。登录成功后界面大致这样:

  3. 3
    记下网关的「地址」和「端口」

    OpenD 界面上会显示监听地址,默认就是 127.0.0.1 和端口 11111。到「管理 → 券商同步」的富途 Futu栏填:

    我们的输入框填什么
    FutuOpenD 地址OpenD 和本系统在同一台机器就填 127.0.0.1;在别的机器就填那台机器的内网 IP
    OpenD 端口11111(除非你在 OpenD 里改过)

    保存后点「测试富途连接」验证。之后到证券账户「持仓 → 券商自动同步」点关联即可。

两个提醒
  • · 查持仓 / 现金不需要「解锁交易」:解锁交易只在下单时才用,我们永远不下单,所以不用输交易密码。
  • · OpenD 若装在云服务器,别把监听地址设成 0.0.0.0 直接开公网端口 —— 用内网 / SSH 隧道更安全。
进 · 阶 · O · p · e · n · D · 手 · 动 · 部 · 署

富途没有「拿 key 直连的云端 API」—— SDK 只能连 OpenD 网关。所以 OpenD 必须一直开着、且本系统能通过 host:port 连到它。主推用顶部的一键安装向导(等价于拓扑 A);以下手动三拓扑供进阶 / 特殊部署形态参考:

A · 与 app 同机

systemd 部署首选。同机常驻命令行 OpenD,填 127.0.0.1:11111。用模板 deploy/futu-opend.service.example。

B · docker 网关容器

compose 部署首选。跑一次 bash deploy/docker-up.sh --with-futu 启用可选网关容器(默认不装);OpenD 由它从富途官网下载并核对 sha256,账号密码在向导页填。

C · 家用机 + 隧道

不想在云机放登录态:OpenD 跑家里,SSH 反向隧道 -R 11111:127.0.0.1:11111 到 prod。

三种都要先在有桌面的机器用可视化版 OpenD 登录一次、过掉首次问卷 + 协议确认,之后 headless 才能用。详见仓库文档 docs/broker-sync-guide.md。

老虎 Tiger 相对简单 · 全程网页操作 · 免装网关
开始前

你得先有一个老虎证券账户并已入金(开放平台对已入金用户免费)。手机上就是「老虎国际 / TigerTrade」那个 App 的账户。

  1. 1
    注册成为开发者

    打开老虎开放平台开发者页,用手机号 + 验证码登录 / 注册(和你的老虎账户同一手机号)。

    developer.itigerup.com
  2. 2
    在「开发者信息」页记下 Tiger ID 和 资金账号

    登录后进入开发者信息 / 个人信息页,你会看到大致这样一屏 —— 把标出来的两项记下来:

    · Tiger ID:一串数字,填到我们的「tiger_id」。

    · 资金账号:环球账号 U 开头(如 U12300123)、综合账号是 5–10 位数字。填到我们的「交易账户」(留空则用默认账户也行)。

  3. 3
    生成 RSA 密钥对,复制「私钥」

    点页面上的「生成 RSA 密钥对」。系统会给出一段公钥和一段私钥。

    最关键的一步,别关页面:私钥只显示这一次、刷新就没了,老虎服务器也不保存。立刻整段复制下来。万一没存到,点「重新生成」再来一次即可。

    我们是 Java 程序,请选 / 保存 PKCS#8 格式的私钥(页面通常有 Java / Python 两种,选 Java 那份)。整段(含 -----BEGIN…KEY----- 到 -----END…KEY-----,或那串纯 Base64)粘到我们的「RSA 私钥」框。

  4. 4
    回本系统填写并测试

    到「管理 → 券商同步」的老虎 Tiger那一栏,对应填入:

    我们的输入框填什么
    tiger_id第 2 步的 Tiger ID
    RSA 私钥第 3 步复制的私钥(PKCS#8)
    交易账户第 2 步的资金账号(可留空 = 默认账户)

    点「保存券商配置」,再点「测试老虎连接」。显示「测试连接成功」就通了 —— 然后到证券账户的「持仓 → 券商自动同步」点关联即可。

盈透 IBKR 全程网页操作 · 免装网关 · 约 10 分钟 · 一年换一次口令
开始前

盈透走的是它的 Flex 报表:你在 IBKR 后台定义一份报表、生成一个「报表口令」,账房每天用它把上一个交易日收盘后的持仓和现金取回来。这是日终数据,不是实时的 —— 对按月看全貌完全够用。

  1. 1
    打开 Flex 报表页

    登录 IBKR 网页后台(Client Portal),打开 Performance & Reports → Flex Queries。

  2. 2
    建一份 Activity Flex Query

    在 Activity Flex Query 那一栏点「+」:勾 Open Positions 和 Cash Report 两栏(字段全选即可),格式选 XML,时段选 Last Business Day,保存。
    保存后它旁边会显示一串数字,那就是查询号。
    两栏一定都要勾:少了哪一栏,账房会拒绝同步并告诉你 —— 不然会被当成持仓 / 现金全部清空。

  3. 3
    打开 Flex Web Service

    点 Flex Queries 页上的 Flex Web Service Configuration(齿轮),勾选启用并保存。

  4. 4
    生成报表口令 · 有效期选 1 年

    点「Generate New Token」:有效期(Should Expire After)选 1 年 —— 默认只有 6 小时,六小时后同步就停了。
    如果知道本服务器的公网 IP,可以填进「Valid For IP Address」,口令就只能从这台服务器用。
    注意:重新生成会让旧口令立刻失效。

  5. 5
    粘回账房,测试

    回 管理 → 券商同步 的「盈透 IBKR」一格:粘上报表口令、查询号,顺手填上口令到期日(一年后的今天)—— 填了,到期前 14 天账房会提醒你换。点「保存券商配置」,再点「测试盈透 IBKR 连接」,会列出找到的账户。然后到证券账户的「券商」页选「盈透 IBKR」关联。

官方参考: Flex Queries · Flex Web Service 配置
